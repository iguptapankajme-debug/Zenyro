# Zenyro

Marketing website for Zenyro, an AI automation studio that helps businesses scale faster.

A single self-contained page: open `index.html` in a browser, or deploy the folder to any static host (Netlify, Vercel, GitHub Pages, Cloudflare Pages).

## Customise
- **Prices**: search for `$490`, `$2,500` and `$900` in `index.html`.
- **Contact form**: set `FORM_ENDPOINT` in the script at the bottom of `index.html` to a form backend (e.g. Formspree) to receive enquiries.
- **Ops feed**: the hero activity feed is sample data; edit the `events` list in the script.
